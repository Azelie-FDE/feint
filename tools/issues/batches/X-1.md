Batch X-1 of `docs/roadmap.md` ("The operational view"); proposed in
`docs/roadmap-scaleway-iaas.md` batch 1, justified by
`docs/roadmap-exoscale-iaas.md` batch 1.

**Delivers.** `Declined()` becomes a list of `(operation, reason)` so the
coverage report can say *why* an operation is refused. Today the reason lives in
comments only a reader of the code ever sees. One interface change, three packs,
and the report that surfaces it. The smallest batch with the widest blast
radius, which is why it is first: it must land before EXO-1 writes ~250 refusals
against the old signature.

**Where the work lands.** `internal/core/emulator/emulator.go:98` (the
`emulator.Pack` interface), the three packs under `internal/providers/`,
`internal/drift/report.go`.

**Depends on.** Nothing.

**Closed by.**

```bash
mise run check
./feint coverage --sdk .upstream/scaleway-sdk-go --products instance,vpc,ipam --format list
# the second command prints a reason next to every declined operation
```

**Done means all four** — the "When a batch is done" conditions of `docs/roadmap.md`:

- [ ] `mise run check` passes (gofmt, vet, golangci-lint, `go test -race`)
- [ ] Every new route declares its upstream `Route.Operation`, and `TestEveryRouteDeclaresAnOperation` proves it
- [ ] `mise run conformance` passes, including this batch's own new evidence
- [ ] `tools/drift/gate.sh check` returns 0, this batch's operations served or declined with a reason
